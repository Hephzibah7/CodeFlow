**CodeFlow** is an interactive code execution visualization platform that helps students, programmers, and interview candidates understand how recursive and dynamic programming algorithms execute internally. Instead of only displaying the final output, CodeFlow visualizes the complete execution process, including the recursion call stack, recursion tree, variable states, return value propagation, and dynamic programming table formation using interactive animations, color-coded highlights, and step-by-step execution. The platform also enables users to experiment by modifying constraints or conditions within their code for example, changing a condition from `x > 0` to `x >= 0` and instantly observe how the recursion tree, call stack, execution path, and overall algorithm behavior change. This allows users not only to understand how their code works internally but also to analyze the impact of different constraints, compare solutions, and develop a deeper intuition for recursion and dynamic programming.
